# Sushmita Mallick — Portfolio

A responsive, dependency-free personal portfolio built with HTML, CSS, and JavaScript.

## Run locally

Open `index.html` directly, or start a local server:

```powershell
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Content

Career details were compiled from Sushmita's provided résumé and public LinkedIn profile. The design takes inspiration from the warm, personal tone and compact navigation of cassidoo.co while using an original layout and visual system.
